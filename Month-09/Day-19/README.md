# 📅 Day 19 — MFU/HFU GPU Hardware Profiling & N-Queens Backtracking

## Overview
Computing Model FLOPs Utilization (MFU) and Hardware FLOPs Utilization (HFU) across GPU architectures alongside implementing LeetCode 52 (N-Queens II) with bitmask-optimized backtracking.

## Components
- `AI/hardware_profiling_mfu_analyzer.py`: 6P theoretical FLOP calculations, MFU efficiency metric derivation, and Roofline profiling.
- `DSA/NQueensBacktrackingTimedSet.java`: $O(N!)$ bitwise N-Queens solver using LSB bit manipulation.
- `Interview/technical_questions.md`: MFU vs HFU distinction and bitwise diagonal tracking proofs.
- `Notes/notes.md`: Transformer FLOP scaling rules and bitmask shift mechanics.
