# 📅 Day 05 — Pipeline Parallelism (1F1B Schedule) & Kruskal's DSU MST

## Overview
Simulating Pipeline Parallelism with 1F1B scheduling and activation stashing alongside solving LeetCode 1135 (Connecting Cities With Minimum Cost) using Kruskal's Algorithm and Disjoint Set Union (DSU).

## Components
- `AI/pipeline_parallel_scheduler.py`: 1F1B vs GPipe scheduling, bubble fraction calculations, and peak memory modeling.
- `DSA/KruskalsDisjointSetMst.java`: $O(E \log E)$ Kruskal's MST with $O(\alpha(N))$ Path Compression and Union by Rank.
- `Interview/technical_questions.md`: 1F1B activation memory bounds and DSU Inverse Ackermann complexity.
- `Notes/notes.md`: Pipeline bubble formulas and interleaved virtual stage topologies.
