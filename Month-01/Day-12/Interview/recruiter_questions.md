# Recruiter Questions — Day 12

**Q: Tell me about a project you built.**
Built a modular PDF RAG chatbot in Python — loads PDFs, chunks text with overlap, stores embeddings in ChromaDB, retrieves top-k chunks, and answers questions using Groq LLM. Fully config-driven architecture.

**Q: What DSA topics have you covered?**
Arrays, HashMaps, Binary Search, Two Pointers, Sliding Window, Stacks, Queues, and Linked Lists — solving LeetCode problems daily in Java.

**Q: Why Python for AI and Java for DSA?**
Python has the best AI/ML ecosystem (LangChain, ChromaDB, Groq). Java enforces strong typing which builds better DSA fundamentals.

**Q: What is RAG?**
Retrieval-Augmented Generation — instead of relying on LLM's training data, we retrieve relevant context from our own documents and inject it into the prompt. More accurate, up-to-date, and controllable.
