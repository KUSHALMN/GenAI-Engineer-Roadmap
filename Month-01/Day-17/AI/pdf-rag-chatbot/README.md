# PDF RAG Chatbot

Day 17 AI project scaffold for the GenAI Engineer roadmap.

## Structure

- `app/` application code
- `retrieval/` semantic, keyword, hybrid retrieval, and reranking
- `evaluation/` benchmark questions and results
- `tests/` unit tests

## Goal

Build a PDF chatbot that can:

1. load documents
2. chunk and embed content
3. retrieve relevant passages
4. rerank results
5. answer questions with cited context
