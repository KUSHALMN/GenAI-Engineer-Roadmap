# Technical Interview Preparation — Voice UX Failure Handling & Intervals
1. Multi-Stage Voice Fallback Strategy: First silence timeout uses a gentle conversational prompt; second failure gracefully suggests screen UI or shuts down the microphone session.
2. Meeting Rooms II Invariant: Sorting start times and using a Min-Heap of end times simulates earliest available room reuse in $O(N \log N)$ time.
